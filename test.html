แบบฝึกปฏิบัติ : HTML Formatting

เรียนรู้การจัดรูปแบบข้อความด้วยแท็ก HTML พร้อมตกแต่งด้วย CSS

🖥ตัวอย่างผลลัพธ์

B: ข้อความตัวหนา

STRONG: ข้อความสำคัญ

I: ข้อความเอียง

EM: ข้อความเน้นย้ำ

U: ข้อความขีดเส้นใต้

MARK: ข้อความที่ถูกเน้น

SMALL: ข้อความขนาดเล็ก

DEL: ข้อความที่ถูกลบ

SUP: x2

SUB: H2O

เกร็ดความรู้

แท็ก HTML Formatting แต่ละแท็กมีหน้าที่แตกต่างกัน เช่นstrong ใช้เน้นความสำคัญของข้อความem ใช้เน้นข้อความmark ใช้ไฮไลต์ข้อความและ del ใช้แสดงข้อความที่ถูกลบการเลือกใช้แท็กอย่างถูกต้องจะช่วยให้เว็บไซต์มีมาตรฐานและอ่านง่ายมากขึ้น
