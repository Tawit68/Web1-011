    ส่งไฟล์ HTML พร้อมไฟล์เเละรูปภาพ

    i

    เกร็ดความรู้

    แท็ก <a> ใช้สำหรับสร้างลิงก์ (Hyperlink) เพื่อเชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือใช้อยู่อีเมลต่าง ๆ โดยใช้แอททริบิวต์ href ระบุปลายทางของลิงก์ แท็ก <img> ใช้สำหรับแทรกรูปภาพ โดยใช้แอททริบิวต์ src ระบุแหล่งที่อยู่ของไฟล์รูปภาพ และ alt ระบุข้อความอธิบายรูปภาพ ซึ่งสำคัญต่อการเข้าถึงได้ (Accessibility) และช่วยแสดงข้อความเมื่อไม่สามารถโหลดรูปได้ • CSS สามารถใช้ตกแต่งลิงก์ด้วย link color, เอฟเฟกต์เมื่อ hover, ขนาดของรูปภาพ, ขอบ (border), มุมโค้ง (border-radius) และเงา (box-shadow) เพื่อให้หน้าเว็บสวยงามและน่าใช้งานมากยิ่งขึ้น
